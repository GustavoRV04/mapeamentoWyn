# Interface web

Interface React + TypeScript + Vite para o sistema Wyn Ativos.

Consulte o [README principal](../README.md) para instruções de desenvolvimento, configuração da API e hospedagem Linux.

A URL padrão da API é `http://localhost:8000`. Para alterar, configure `VITE_API_URL` antes de executar `npm run build`.

Comandos disponíveis:

```bash
npm run dev
npm run lint
npm run build
```
